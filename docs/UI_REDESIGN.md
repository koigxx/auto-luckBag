# 界面与交互改造

## frontend-design 第二轮方案

本轮在 macOS 开发环境安装并读取 `anthropics/skills` 的 `frontend-design`，延续上一轮已完成的操作反馈与无障碍处理。

- 色彩：画布 `#f5f6f8`、内容 `#ffffff`、正文 `#242731`、导航 `#20232d`、操作 `#d91f4b`、确认 `#247458`。颜色表达操作和状态，不增加装饰渐变。
- 字体：macOS 使用 PingFang SC，Windows 使用 Microsoft YaHei UI；正文配合本地系统西文字体。标题 26px、区域标题 18–23px、正文 14px、说明 12–13px；倒计时使用等宽数字特性。
- 布局：启动区是首页的视觉重点；策略摘要作为安静的辅助栏。未运行时压缩空房间区域，隐藏无内容候选和重复预算；真实历史数据保留。运行时恢复完整的倒计时、资源和预约队列。
- 设置：先呈现当前组标题与选择项，再展示快捷方案，限制说明就近放置；分组导航带简短用途说明，保留统一保存与草稿行为。
- 记录：按“范围与汇总 → 待办 → 明细”阅读，范围区使用与明细不同的底色；选中页签用边线与底色共同表达。金额、确认状态和未知结果保留原含义。

```text
启动：  本次运行选项 / 开始       已保存策略 / 预算
        最近一次运行数据
        手动参与入口（紧凑）

运行：  当前状态 / 停止
        本次运行数据
        当前房间 / 预算          按时间排列的预约

设置：  分组及用途               标题 / 核心选择 / 快捷方案
                                固定可见的保存与还原
```

方案复核：放弃新增主题、大图和装饰动画，现有直播任务倒计时本身就是产品特征。此次通过运行前后不同的信息密度建立层级，不将每项内容再包装成相同卡片。设置分组不是步骤，因此不添加序号；仅异常处理保留真实流程编号。

本轮验收：类型检查、185 项离线回归、152 项 UI 交互/布局检查及隔离 Electron / 通知冒烟全部通过。新增检查覆盖启动页预算不重复、保留手动入口、运行后恢复监控、设置主选项优先于快捷方案。已复核启动、运行、设置和记录截图，并用 computer use 确认开发应用热更新后的界面已生效，未启动真实任务。截图位于忽略目录 `.test-output/ui-*.png`；不生成安装包。

## 设计判断

现有界面把大量表单、候选、日志和历史记录按相同权重堆在一页。用户难以确认下一步是登录、修改策略还是启动，也难以区分“已提交”和“已生效”。本轮围绕现有 Electron + Vue 工作流优化，不修改参与、预算和风险规则。

技能选择：`anthropics/skills` 的 `frontend-design` 适用于已有界面的视觉重构，要求先明确设计、再实现并用截图检验。Figma 系列技能主要用于设计稿协作，本项目没有现成 Figma 稿，直接在 Vue 中实现和校验更合适。

已通过技能安装器安装到 `C:/Users/Administrator/.codex/skills/frontend-design/`，并读取应用其设计流程。来源：[官方 SKILL.md](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)。完整仓库下载中断后改用安装器的 Git 模式成功安装。没有安装额外的运行依赖或连接设计账户。

## 设计约定

- 颜色：侧栏墨色 `#20232d`，画布浅灰 `#f5f6f8`，内容白色 `#ffffff`，正文 `#242731`，主操作玫红 `#d91f4b`，成功状态绿色 `#247458`。截图复核后提高了辅助文字字号和对比度。
- 字体：Windows 中文界面优先 Microsoft YaHei UI，英文 Segoe UI；正文 14px，辅助 12px，标题 26px，统计 28px。数字使用等宽数字特性，不把辅助标签全部变成等宽字体。
- 布局：窄侧栏加独立工作区。正文左对齐；右侧仅放预算/计划摘要。表格承担历史比较，主页面用任务区域和统计分隔行，避免所有内容都变成同样的卡片。
- 特征：玫红用于开始与保存，停止使用清晰的文字和轮廓；风险同时用图标和文字。无装饰渐变、无自动循环动画、无虚构数据。

```text
侧栏            标题 / 说明                   语言 / 账号
运行面板        当前状态、开始或停止          本次计划
策略设置        参与 / 中奖 / 支出 / 待核对   预算摘要
房间库          当前直播间                   候选队列
运行记录
运行日志        各视图独立展示，设置草稿保留
```

方案复核：这是需要长期运行、偶尔介入的桌面工具，因此使用紧凑导航、固定可找到的停止操作、明确的空状态和错误恢复入口。移除旧版首屏全部参数并列和多个重复统计区域；运行中禁用会改变执行策略的表单。小窗口折叠侧栏文字，内容改为单列。

## 交互要求

- 登录未完成时主操作引导登录；启动、停止、保存、添加房间有各自等待状态，禁止重复提交。
- 设置按参与偏好、支出与粉丝团、运行与休息、高级设置分组；统一保存、还原，校验失败显示具体字段提示。
- 未保存草稿跨视图保留，启动前提示处理草稿；运行中只读。
- 扫描参数从主进程默认配置读取。倒计时继续由主进程推送。
- 记录中的 unknown、未决支付和未确认参与保留真实含义；风险处理与账本核对仍需明确操作。
- 手动添加失败保留输入；键盘可完成导航、表单和弹窗操作；支持 Escape 关闭及可见焦点。
- 日志可搜索、暂停自动滚动和清空显示；清空显示不影响账本。
- 离线验证空状态、运行、休息、风险、保存失败、窄窗口和中英文；截图使用明确的模拟数据。

## UI UX Pro Max 交互优化

本轮使用 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的设计检索与检查流程。技能安装于开发者的 Codex 技能目录，不加入应用依赖或发行包。首次 design-system 检索偏向运营落地页；改用 `data dense dashboard --domain style` 后得到适合工具型产品的 Data-Dense Dashboard。另查询 `loading feedback cancellation --domain ux`、`error summary validation --domain ux` 和 Vue 的动态 ARIA 指南，按现有桌面项目约束应用。

采用浅色任务工作台方向：保留红色主操作、本地系统字体和 SVG 图标；复用现有设置、筛选、分页、原生弹窗和草稿保留机制。没有引入外部字体、组件库或新的配色主题。

- 启动前直接显示运行方式、发现入口和时长，背景模式卡片同时说明窗口行为。常用时长 30/60/120 分钟及“按计划”可点选，选中状态通过文字、边框和 `aria-pressed` 表达；主进程仍执行原有计划和额度约束。
- 定时输入在字段旁反馈非法值，使用 `aria-invalid` 和关联描述；错误时阻止启动。准备运行期间锁定输入，显示具体状态和取消启动入口。
- 区分人工登录、后台校验、启动准备及停止清理的文案。运行区明确解释两种停止方式，已请求收尾时说明不接新轮；状态由实际 IPC 与主进程状态驱动。
- 异常区增加三步处理说明，突出支付待核对前置条件；打开浏览器时显示等待反馈，不自动解除风险或恢复运行。
- 增加键盘跳转主内容入口，提高焦点轮廓对比度，保留减少动态效果支持；新增布局适配窄窗口。

验收使用全请求拦截的 Vue 夹具与隔离 Electron 配置，不操作真实账号。新增检查覆盖非法时长、快捷时长及复位、输入锁定、待启动反馈、键盘跳转、减少动态效果与窄窗口重排。预览图：`.test-output/ui-start-options.png`、`.test-output/ui-overview-running.png`、`.test-output/ui-records-review.png`。类型检查、185 项离线回归、145 项界面交互/布局检查及隔离 Electron / 通知冒烟通过。截图采集前回到页首，避免固定导航因滚动位置出现在全页截图中部。
