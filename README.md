# Auto LuckBag

抖音直播福袋发现与参与的 Windows 桌面工具，使用 Electron、Vue、TypeScript 和 Playwright。当前版本加入了历史房间复访、机会与成本排序、粉丝团预算账本、有限连续参与，以及分段运行与计划休息。

完整改造范围见[迭代清单](docs/ITERATION_PLAN.md)，验证结果、已修复问题与限制见[交付记录](docs/DELIVERY.md)。

界面已重构为运行面板、策略设置、房间库、运行记录和日志五个入口，设计及界面验收见 [UI 改造记录](docs/UI_REDESIGN.md)。

## 主要功能

- 历史房间独立复访，支持收藏、屏蔽和主播付费许可；失败房间有持久化冷却。
- 三种目标：机会/时间、钻石净增估计/时间、实物机会。未知竞争度明确降级，不用在线人数推算中奖概率。
- 按发现顺序逐房验证，证据齐全即可提前结束；候选按任务占用区间与导航间隔预约，探索不得延误返房。任务准备时间与导航冷却分开计算。
- 粉丝团策略支持仅已有资格、优先复用、仅指定主播付费。限制总预算、每日支出、每位主播累计支出、单次费用和每日新开团数。
- 支付先预留，成功后确认，未知结果待核对；重置展示统计不会清空账本或增加额度。
- 优先点击福袋弹窗的一键评论；仅有粉丝团入口时，在等级、预算及时间允许下先完成粉丝团，再评论。不自动向聊天框发送口令；分享和无法确认的任务跳过。
- 同房最多连续参与配置轮数，每轮独立结算。等待下一袋和总停留时间均有限制。
- 运行、收尾、休息与恢复检查分开；停止立即取消后续动作。明确安全挑战不自动重试。
- 主进程计算倒计时；房间库、预算、未知结果、策略原因与脱敏导出可查看。

## 安装与开发

需要 Windows、Node.js 18+ 和 npm。开发测试使用 Playwright Chromium：

```bash
npm install
npx playwright install chromium
npm run dev
```

运行程序优先使用已安装的 Playwright Chromium；没有该运行时时尝试本机 Microsoft Edge。测试脚本需要 Playwright Chromium。

```bash
npm run typecheck
npm test
npm run test:smoke
npm run build
```

`npm test` 使用内存账本、虚拟时钟和拦截全部网络请求的浏览器夹具；不发送真实评论、关注或付款。`test:smoke` 在独立临时用户目录检查 Electron 启动、迁移备份、IPC 和界面。

日常开发默认不生成安装包，`npm run build` 仅编译代码。仅在明确要求生成 Windows 安装包时运行 `npm run build:win`；`build:win:dir` 和 `build:win:cn` 同样是按需发行命令，不属于日常回归步骤。

## 使用

1. 点击登录，在浏览器完成登录，等待应用确认账号。
2. 在“策略设置”按参与偏好、支出与粉丝团、运行与休息、高级设置四组配置，点击“保存设置”。未保存的草稿可跨页面保留，启动前需保存或还原。
3. 回到“运行面板”点击“开始运行”。本次发现入口和定时停止位于“本次运行选项”。运行中可在任何页面顶部点击“停止”。
4. 在房间库查看资格及复访时间；停止计划后可修改收藏、屏蔽、付费许可和策略。
5. 若出现未决支付，在“运行记录”的待处理区核对抖音实际扣款，再明确确认已扣款或未扣款。风险解除后需手动启动。

基础预算是账号内所有房间累计可使用的上限，不是钱包余额。允许使用利润时，仅已确认钻石奖励按比例和追加上限增加额度。未决支出继续占用额度，免费资格不受余额耗尽影响。

默认设置（2026-10-23 调度修复）：扫描间隔120秒、开奖前任务准备窗口45秒、候选池5；首页扫描完成后单独等待20秒验证首房，直播间导航间隔90–120秒；每小时最多40次导航、30个新房。验证至少3秒，身份、任务、可靠倒计时齐全即可结束；首次最多28秒、预约返房最多12秒。任务准备窗口与返房耗时分开：另外预留加载30秒、复验12秒和调度3秒，普通候选默认约开奖前90秒开始返房；复杂任务或看播需更多时间，时间不足不付费。导航冷却由预约调度单独预留。参与中的房间不会因导航间隔到期退出；同房连轮不得拖延已预约候选。单段运行25–40分钟、休息10–20分钟，每天最多活跃460分钟；单房连续最多6轮、驻留20分钟、等待下一轮60秒。随机时长每段只生成一次。源码默认值不会覆盖用户已保存配置；现有 `enterBeforeSeconds` 数值保留，但现在表示任务准备窗口，实际返房还会加上述预留。

福袋一键评论优先；仅显示关注前置按钮时先关注、确认后再评论，仅显示粉丝团入口时沿用预算与资格检查后先入团。开奖结果只读取可关联本轮的本人弹窗；中奖明细支持钻石数量及明确的物品名称、数量、单位，数量未知显示待确认，不当作0或计入奖励预算。开奖后仍最多观察25秒，未获可靠结果保留未知。

默认总预算和每日支出均为 50 钻、单次 1 钻、主播累计 5 钻、每日新开团 50 个；开启已确认钻石奖励再投入（比例 100%、追加额度上限 10 钻），探索比例 60%。优先复用策略允许首次发现且时间、任务、预算均满足时付费参与；分享任务仍跳过。默认开启调试日志。旧的已保存配置仍优先生效，修改源码默认值不会覆盖用户设置。

## 数据与限制

配置和明细保存在 Electron 用户数据目录：`config.json`、`runtime-v2.json`、`auth.json`。首次升级生成 `config.json.before-runtime-v2.bak`。旧中奖汇总不自动变为可花额度；应用重启不会自动进房。回退步骤见[使用说明](docs/USAGE.md)。

本次只完成离线逻辑、界面和构建验证，没有实测线上中奖提升。平台页面、按钮和响应格式变化可能导致识别失败；遇到未知任务、身份或费用会跳过。仅可见倒计时而无法确认本轮身份和任务时进入复验，不猜测参与资格。二进制 WebSocket 尚无通用解码支持。

低频与休息用于减少操作量，不保证规避风控。平台规则研究及原始来源记录在[迭代清单](docs/ITERATION_PLAN.md)；其中自动化接入限制仍然适用。
